Leitor de Código de Barras Online

Sobre o Leitor de Código de Barras Online

O Leitor de Código de Barras Online é uma ferramenta gratuita que permite ler e decodificar códigos de barras diretamente pelo navegador, sem precisar instalar nenhum aplicativo. Basta usar a câmera do celular ou computador, ou enviar uma imagem salva, para obter o conteúdo do código instantaneamente.

Formatos suportados

A ferramenta suporta os principais formatos de códigos de barras 1D e 2D utilizados no mundo:

  • 1D: EAN-13, EAN-8, Code 128, Code 39, Code 93, Codabar, UPC-A, UPC-E, ITF, RSS-14
  • 2D: QR Code, PDF-417, Data Matrix, Aztec

Para que serve?

Esta ferramenta é útil em diversas situações: verificar o conteúdo de um QR Code antes de acessar um link, consultar o número de um código de barras de produto, conferir dados de boletos, etiquetas logísticas, ingressos digitais e muito mais. Funciona em qualquer dispositivo com navegador moderno — celular, tablet ou computador.
